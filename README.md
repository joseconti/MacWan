# MacWan

A native macOS app (Apple Silicon) that installs, updates and runs the open
[Wan](https://github.com/Wan-Video) video generation models — text-to-video, image-to-video,
first/last-frame, VACE editing, character animation — through a visual interface, with no Terminal.

Status: planning (Keel Phase 2 — specification and spikes). Start with [`docs/README.md`](docs/README.md).
